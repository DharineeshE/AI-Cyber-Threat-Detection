# Dataset

This folder contains the network traffic data used by the AI Cyber Threat Detection System.

## Sample Dataset

`sample_network_traffic.csv` is a small educational dataset created for demonstrating the machine learning workflow.

It contains network traffic features such as:

* Connection duration
* Network protocol
* Service type
* Source bytes
* Destination bytes
* Failed login attempts
* Connection count
* Threat label

## Threat Classes

The sample dataset contains these categories:

* `normal`
* `dos`
* `probe`
* `r2l`

## Important Note

The sample dataset is intended for **educational and demonstration purposes**. It is not a real-world network security dataset and should not be used to make production security decisions.

For more realistic experimentation, the project can later be extended with a recognized public cybersecurity dataset.
