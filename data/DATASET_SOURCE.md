# 📊 UNSW-NB15 Dataset Source

## Official Dataset

This project can be extended using the **UNSW-NB15 Network Intrusion Dataset** provided by UNSW Canberra.

The dataset contains network traffic with normal activity and multiple attack categories.

## Dataset Details

* Records: 2,540,044
* Features: 49
* Attack Types: 9
* Training Records: 175,341
* Testing Records: 82,332

## Attack Categories

* Fuzzers
* Analysis
* Backdoors
* DoS
* Exploits
* Generic
* Reconnaissance
* Shellcode
* Worms
