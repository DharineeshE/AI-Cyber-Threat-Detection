# Security Policy

## Overview

This repository is an educational cybersecurity and machine learning project.

It is intended to demonstrate how machine learning can be applied to network traffic analysis and threat classification.

## Supported Versions

Currently, only the latest version of the project is maintained.

## Reporting a Security Issue

If you discover a genuine security issue in the project:

1. Do not publicly disclose sensitive details.
2. Open a GitHub issue with a clear description.
3. Include steps to reproduce the problem when possible.
4. Do not include passwords, API keys, personal information, or other sensitive data.

## Responsible Use

This project is intended for educational, research, and authorized testing purposes only.

Do not use the software to monitor, attack, scan, or access systems without proper authorization.
